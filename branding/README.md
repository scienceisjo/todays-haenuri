# 학교 로고

이 폴더에 **logo.png**(권장: 정사각형 512×512 이상, 배경 투명) 또는 **logo.svg**를 넣으면
`npm run demo`(새 데모 DB)와 `npm run setup`(운영 첫 설치)이 그 파일을 학교 로고로 설치합니다.
이미 실행 중인 서버는 앱의 **학교 설정 → 학교 로고**에서 올리면 즉시 반영됩니다.

PNG가 정사각형 192px 이상이면 Windows 설치 앱(PWA) 아이콘까지 로고로 바뀌고,
SVG나 작은 PNG는 사이드바·로그인·브라우저 탭에만 쓰이고 설치 아이콘은 기본 아이콘을 유지합니다.

원본에 흰 배경이 있거나 정사각형이 아니면 다음 명령으로 다듬을 수 있습니다(외부 프로그램 불필요):

```bash
node scripts/logo.mjs "원본 로고.png"
```

현재 `logo.png`는 해누리중학교 엠블럼(680×680, 배경 투명)입니다.
