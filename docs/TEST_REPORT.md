## 일괄 등록 테스트 10개 (`tests/import.test.mjs`)

1. 인코딩 자동 감지: UTF-8 BOM · UTF-8 · CP949(EUC-KR 바이트) · UTF-16LE

3. .xlsx 첫 시트 읽기(테스트용 최소 ZIP 생성기로 만든 파일): 공유 문자열·XML 이스케이프·숫자·엑셀 날짜 일련번호
4. 날짜 8가지 표기와 엑셀 일련번호 → YYYY-MM-DD, 연도 없는 날짜·2월 30일 거절, 시간 5가지 표기·오전 12시·엑셀 시간 분수
5. 교직원 이름 해석: 공백 무시, 이메일, 동명이인 오류, `이름(부서)`·`이름·부서` 구별, 없는 부서, 없는 사람
6. 급식지도 양식: 그 달 수업일만(휴업일 제외), UTF-8 BOM 바이트, 로그인 필요
7. 급식지도 미리 보기: 정상·형식 오류·동명이인·같은 사람·파일 안 중복·기존 자료(수정 권한 표시)·빈 행 건너뜀, 요약 집계
8. 급식지도 저장: 오류 시 전체 거절(400) → skip_invalid로 부분 저장, 중복 기본 건너뛰기, 갱신은 작성자·관리자만(403 대신 행 오류), 갱신 후 version 증가, 빈 행 include_empty
9. .xlsx 업로드로 급식지도 미리 보기→저장 후 다른 계정 bootstrap에서 확인
10. 학사 일정: 유형 인식, 휴업일 행 관리자 제한, 예시 행 건너뜀, 알 수 없는 유형 오류, 파일 안 중복, 전체 거절→부분 저장, 재업로드 시 기존 중복 감지·건너뜀, 갱신 모드로 장소 변경

## v0.3.0에서 실제 브라우저로 확인한 것 (데모 서버, 파일은 DataTransfer로 주입)

- 급식지도 월간표 → CSV·엑셀 일괄 등록 → 5행 CSV 올리기 → 미리 보기(기존 자료 ‘현재→파일’ 비교, 같은 사람 오류, 빈 행 건너뜀, 요약) → ‘파일 내용으로 갱신’ + ‘오류 행 제외’ 저장 → 토스트·대시보드 반영
- 새 안내 폼에서 행사·회의를 매주 월·수 4회 반복 등록 → 4회차 생성·↻ 달력 표시 → 2회차 상세(‘반복 · 2/4회차’) → 수정 창 적용 범위 ‘이후 모두’로 장소 변경 → 1회차 유지·2~4회차 변경 → 1회차 삭제 창 범위 ‘전체’ → 4회차 취소
- 전체 일정 → 학사 일정 일괄 등록 → 휴업일·예시 행 포함 CSV → 저장(일정 2·휴업일 1·건너뜀 1) → 학교 설정 휴업일 카드에 표시
- 기존 데모 DB에 마이그레이션 002 적용(레코드 18·사용자 4 보존) 확인
- 학교 설정에서 512px PNG 로고 올리기 → 사이드바 마크·파비콘 주소가 새 버전으로 바뀌고 실제 512px 이미지 표시 → ‘기본 아이콘으로 되돌리기’ → 기본 아이콘(64px) 복귀

## v0.2.0에서 실제 브라우저로 확인한 것 (Edge 계열, 데모 서버)

- 로그인(데모 관리자) → 대시보드 렌더링, 급식지도 두 자리 표시
- 오늘/이번 주 전환, 주간 화면의 날짜별 두 자리
- 급식지도 담당자 변경 저장 → 대체 사유(비고)까지 대시보드 반영
- 급식지도 월간표: 월 이동, 미지정/예약 집계, '빈 날짜만 보기' 필터, 빈 날짜 '담당자 지정'(그 날짜 자동 입력)→저장→표 반영
- 파일 없는 새 공지 등록 → 즉시 게시 상태 확인(리팩터한 저장 흐름 회귀 확인)
- 이미지 첨부 미리 보기 응답: Content-Type image/png, Content-Disposition inline, 한글 파일명 인코딩

## 아직 확인하지 않은 것

- 첨부 파일 선택(input) 업로드 UX와 부분 업로드 실패 후 재시도(서버 계약은 테스트 18로 검증)
- **실제 한국어 엑셀(Microsoft Excel·한셀)이 저장한 .xlsx·CSV 파일** — .xlsx 리더는 표준 구조를 따르는 테스트용 파일로 검증했고, 엑셀이 만든 실제 파일(스타일·날짜 서식·병합 셀·빈 행)로는 아직 확인하지 않았다. 문제가 생기면 ‘CSV UTF-8’ 저장으로 우회할 수 있다.
- 브라우저 PDF 미리 보기 실물
- 학교 Windows 버전별 start-demo.bat, Edge 설치·로그인 유지·시작프로그램 동작
- 실제 중앙 서버/HTTPS/기관망·프록시 환경
- Microsoft 학교 계정 연동
- 대규모 파일·사용자 부하, 운영 수준 보안 점검·백업 복원 훈련

자동 API 테스트 통과를 브라우저 테스트 통과로 표현하지 않는다. 위 '확인한 것'은 데모 서버에서 직접 조작해 확인한 범위다.
