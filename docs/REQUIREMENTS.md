# 요구사항 및 진행 상태

사용자가 직접 정한 목적은 **선생님 각자의 Windows 컴퓨터를 켰을 때 자동으로 열리는 교사용 학교 알림장**이다(교실 전자칠판용이 아니다).
모든 교직원은 앱에서 직접 입력할 수 있고, 아침에 한 화면에서 필요한 정보를 확인한다.
급식지도는 '식당 입구', '식당 내부' 각 한 명으로 고정한다.
창체의 날 교육 내용은 교무기획에서 보내는 시간표 파일과 함께 확인한다.

이전 대화의 기능 제안 전체를 첫 배포 완료라고 간주하지 않는다. 아래 표가 초안의 실제 상태다.

| 요구사항 | v0.1.0 상태 |
|---|---|
| 오늘 날짜·요일·한국 시간 | 구현 |
| 오늘·내일·이번 주·선택 날짜 | 구현 |

| 전체 공지·부서 안내 | 구현 |

| 개인별 제출 완료·미제출 추적 | 구현하지 않음. 공지 읽음과 별개 |
| 창체 교육 내용·파일 첨부 | 구현 |
| PDF·이미지 미리 보기 | 이미지 미리 보기 응답(서명 감지·inline·한글 파일명) 브라우저 검증. PDF 실물 미검증 |
| 첨부 포함 안내 원자적 게시 | 구현(초안→업로드→게시 확정, 실패 시 본문 비공개 유지·이어 올리기) |
| 한글·엑셀·워드 | 업로드/다운로드. 자동 변환·시간표 추출은 후속 |
| 모두 직접 등록·즉시/예약 게시 | 구현, 기본 승인 대기 없음 |
| 임시저장·게시 종료·숨김 | 구현 |
| 관리자·작성자 권한 | 서버 검사 구현 |
| 부서별 열람 대상 | 구현. 학년·개인 대상은 후속 |

| 읽음 | 본인 읽음 구현. 관리자별 미확인자 집계는 후속 |
| 파일 저장 | 서버 디스크 구현. 객체 저장소 연동은 미구현 |
| 검색·유형/부서 필터·월간 달력 | 구현 |
| 반복 일정·회차 예외 | 구현(매주·매월·간격·종료일/횟수·휴업일 제외, 회차별 수정·취소, 이후/전체 범위 수정·취소) |
| Excel/CSV 일괄 등록 | 구현. 파일을 첨부하는 기능과 구별 |
| 교직원 추가·부서 지정·비활성·권한 변경 | 구현 |
| 부서 관리 | 해누리중학교 14개 기본 구성 + 추가 구현. 수정/삭제는 후속 |
| 학교명·앱 이름 | 설정 구현(앱 이름 기본 「오늘의 해누리」) |
| 로고 | 구현(관리자 업로드, 사이드바·로그인·탭·PWA 아이콘). 공식 엠블럼 파일은 사용자 제공 대기 |
| 카드 순서·표시 여부 | 후속 |
| 삭제 글 복구 | 공지/일정 구현. 급식·지도·파일 복구는 후속 |
| 수정 기록 | 주체·동작·제목·시간. 변경 전후 전체본은 후속 |
| JSON 내보내기 | 구현. 완전 백업과 구별 |
| 자동 백업·복원 | 후속 |
| 다중 사용자 데이터 공유·지속 저장 | 같은 서버의 SQLite로 구현 |
| 자동 갱신 | 30초 polling, 창 활성화·온라인 복귀 시 갱신 |
| 오프라인 마지막 자료 | 열린 창의 메모리만 유지. 재실행 시 복원은 후속 |
| Windows 앱 형태 | PWA 파일 구현, 실제 Edge 설치 확인 필요 |
| Windows 자동 시작 | 사용자 설정 방법 문서화, 장치 검증 필요 |
| 배포된 중앙 서버·HTTPS | 미배포 |
| 모바일 반응형 | CSS 구현, 실제 브라우저 검증 필요 |

개발자 판단으로 정한 기본값: 한국 표준시, 중식 1회, 관리자 발급 계정, 월간 달력 시작 요일 일요일, 주간 목록 월~일.
학교의 실제 교직원 명단·부서 구조·중앙 배포 주소·Microsoft 테넌트 정보는 제공받지 않았다.
데모의 학교명은 설정에서 변경 가능하며 사람·일정·급식은 가상이다.
